# Reference Notes

Sample content written for the prototype.

Binary search works only when the data is sorted into a known order. It checks the middle item, compares it with the target, and discards the half that cannot contain the target. It repeats until the item is found or the remaining search interval is empty. An empty list or exhausted interval means the item is not found.

Bubble sort compares adjacent pairs. If a pair is in the wrong order, the algorithm swaps them. Repeated passes move large values to the end of the list. The algorithm can stop when a pass makes no swaps or when the required passes are complete.

Recursive algorithms call themselves. A base case is a condition that stops recursion. The recursive call should move the problem closer to the base case; otherwise recursion may continue until stack overflow or a crash.
