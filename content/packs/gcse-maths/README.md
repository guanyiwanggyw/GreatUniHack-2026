# GCSE Maths pack

- `pack.json` lists the GCSE topics Chud's brain tracks, with keywords the offline agents use to tag teaching notes, and common misconceptions the fact checker flags.
- `reference.md` is the reference the fact checker compares teaching against.
- `questions.json` holds six practice questions written for this prototype.
- `papers/` holds past papers uploaded on the Past papers page. Each paper is its own JSON file, so uploading never overwrites anything.
- `sample-paper/` has a short practice paper and mark scheme as PDFs, for trying the upload flow.

Real past papers belong to their exam board. Credit the board and keep uploads private unless you have a licence.
